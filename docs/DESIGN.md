# Design

Reasoning: fresh-context independent host agents. Control: architecture router and
ten focused workflows. Execution: version-bound Node core and thin OS adapters.
Review packages copy raw categorized bytes and Git revision; candidate/report hashes
bind review to artifacts. A script cannot prove agent identity: host traces are
mandatory and actual independent reviews remain separate from simulated unit tests.
Freeze stages artifacts and verifies integrity/parity before updating CURRENT last.
Existing proposals require per-path approvals and before hashes; DevOps is preserved.
Installer copies skills and private runtime only; no project initialization.
Project/global runtimes retain own versions and dependencies without npm exec cache.
Architecture version is independent of suite/package version. Explicit unchanged
version instructions retain prior revision artifacts. PDF uses PDFKit; PlantUML
uses configurable Java JAR; Unicode requires configured embeddable font.
GitHub policy separates non-bypass integrity/check rules from PR-only admin bypass.

## 1.1.0 discussion design

One authoritative WORKING.json, one coordinator, protected expectedRevision + atomic
rename. Stable definition/concern IDs drive scheduling and dependencies. User/default/
norm evidence differs from proposals; closed nodes require sourced provenance.
Priority chooses the next missing answer; active dependencies determine validity.
Changes preserve stale downstream values and invalidate candidate/review links.

contentRevision and digest bind substantive nodes/records/baseline only. Lifecycle
phase, current review/architecture and final archive references do not enter the
input hash. Immutable review-input snapshots preserve raw evidence across phase
advancement; final artifacts embed hashed STATE.json without referencing future
mutable state or creating snapshot/manifest hash cycles. Final archives are
idempotent, with explicit legacy recovery and new-discussion baseline links.

Completion binds stored architecture location/version/revision/candidate and approved
Validation Contract. Existing paths/norms remain inherited; real independent behavior
and DevOps preservation are required without imposing Greenfield governance layout.
The host authenticates users/coordinators and independent agents; structural hashes
cannot establish human authorization or semantic correctness.
